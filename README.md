# Project Introduction

This project is part of The Odin Project Foundations course and aims to get practice with the basics of HTML by building a simple webpage.

## Skills Showcased

Upon completion of this project I have demonstrated my skills around:

- Knowing and understanding HTML elements, tags and basic HTML boilerplate.

- Using the various elements to create paragraphs and format text using bold and italics.

- How to add comments and use nested HTML elements effectively.

- Creating ordered and unordered lists.

- Adding links and images.

Overall this project will help develop my knowledge around HTML structure and provide a good base to start learning CSS and JavaScript.
